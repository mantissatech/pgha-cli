Install pgha

pgha is one binary. Pick the method for your system. All builds are on the GitHub releases with checksums.

macOS and Linux

The script checks the checksum, then copies pgha to /usr/local/bin or ~/.local/bin.

$ curl -fsSL https://github.com/mantissatech/pgha-cli/releases/latest/download/install.sh | sh

Homebrew

On macOS and Linux.

$ brew install mantissatech/tap/pgha

Ubuntu and Debian

The apt repository is not signed yet, so this uses trusted=yes.

$ echo "deb [trusted=yes] https://mantissatech.github.io/pgha-cli stable main" | sudo tee /etc/apt/sources.list.d/pgha.list
$ sudo apt update && sudo apt install pgha

Fedora and RHEL

The yum repository is not signed.

$ sudo tee /etc/yum.repos.d/pgha.repo >/dev/null <<'EOF'
[pgha]
name=pgha
baseurl=https://mantissatech.github.io/pgha-cli/yum
enabled=1
gpgcheck=0
EOF
$ sudo dnf install pgha

Windows

With Scoop, or download pgha_windows_amd64.zip from the releases and put pgha.exe on PATH.

> scoop bucket add mantissa https://github.com/mantissatech/scoop-bucket
> scoop install pgha

Other packages

Alpine (.apk), Arch Linux (.pkg.tar.zst), .deb and .rpm files are attached to each release.
