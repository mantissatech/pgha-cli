Section 20

Operations

Run these commands on a node, as root.

#See the cluster

patronictl -c /etc/patroni/config.yml list

#Planned leader change

patronictl -c /etc/patroni/config.yml switchover

Use this before you restart or resize the leader.

#Restart Postgres

patronictl -c /etc/patroni/config.yml restart <name> <member>

#Change a Postgres setting

patronictl -c /etc/patroni/config.yml edit-config

Patroni applies the change on all nodes. Some settings need a restart. patronictl list shows "Pending restart".

#Rebuild a broken replica

patronictl -c /etc/patroni/config.yml reinit <name> <member>

#Check etcd

ETCDCTL_API=3 etcdctl --endpoints=http://127.0.0.1:2379 endpoint health
ETCDCTL_API=3 etcdctl --endpoints=http://127.0.0.1:2379 member list

#Check PgBouncer

psql -h 127.0.0.1 -p 6432 -U pgbouncer pgbouncer -c "SHOW POOLS"
psql -h 127.0.0.1 -p 6432 -U pgbouncer pgbouncer -c "SHOW STATS"

The password is pgbouncer_password in the state file. cl_waiting shows the clients that wait for a connection.

#Open a superuser session

runuser -u postgres -- psql

#Grow a volume

  1. Resize the volume in the Hetzner console. A volume can grow, not shrink.
  2. On the node: resize2fs /dev/disk/by-id/scsi-0HC_Volume_<id>.
  3. Do this for all nodes.

#Things to monitor

With --monitor or pgha monitor install, each node checks replication lag, free space on the data directory, the backup repository, PgBouncer cl_waiting, a missing primary, a missing member, and local Patroni. Read section 18.
