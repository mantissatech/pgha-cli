Section 9

Cloud resources

For a cluster with the name prod:

ResourceNameNotes
SSH keyprod-keyOnly if the tool uploads your public key.
Networkprod-net10.0.0.0/16 with subnet 10.0.1.0/24. With --network, the cluster uses that network and does not label it.
Firewallprod-fwSee below.
Volumesprod-pg1-data ...Format ext4, one for each node.
Serversprod-pg1 ...Private addresses 10.0.1.11, .12, .13. On an existing network, the first free addresses from host 11.
Load balancerprod-lbPrivate address in the subnet.

All resources have the label pgha-cluster=prod. status and down find the resources with this label.

Other labels on servers:

LabelMeaning
pgha-ssh=public or tailscaleHow the tool reaches the node with SSH.
pgha-pgbouncer=trueThe node runs PgBouncer.
pgha-adopted=trueThe server existed before the cluster.

#Firewall rules

ModePublic inbound rules
DefaultTCP 22 from the --ssh-allow ranges.
--tailscaleUDP 41641 from all addresses. No SSH rule.

Hetzner firewalls do not filter the private network. The Postgres, Patroni, etcd and PgBouncer ports are not open to the internet.
