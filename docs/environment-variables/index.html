Section 7

Environment variables

VariableUsed byMeaning
HCLOUD_TOKENallHetzner API token.
PGHA_S3_ACCESS_KEYupS3 access key for backups.
PGHA_S3_SECRET_KEYupS3 secret key for backups.
TS_AUTHKEYup, adoptTailscale auth key.
PGHA_ALERT_WEBHOOKup --monitor, adopt --monitor, monitor installHTTPS webhook for alerts.
PGHA_SOURCE_URLdb importSource URL, in place of --from.
PGHA_CONSOLE_TOKENconsoleLogin token, in place of a random one.
PGHA_MODEalllocal or remote, in place of --mode.
PGHA_DBallSQLite state file, in place of --db.

The tool stores the S3 keys, the Tailscale key, and the webhook in the state file on the first run that needs them. A later command does not need the variables. A stray PGHA_ALERT_WEBHOOK does not change the file unless --monitor is set or monitor install runs.
