Section 19

Troubleshooting

ProblemCause and action
set HCLOUD_TOKEN or use --tokenThe token is missing. Export HCLOUD_TOKEN.
the token you have provided is invalidWrong token, or a read-only token.
servers exist but their saved secrets are missingUse the right --state-dir or --db, or run pgha state import.
Bill warning: server type not availableSelect another --server-type or other --locations.
status shows starting for more than 10 minutesRead /var/log/pgha-bootstrap.log on the node.
load balancer is not attached to a networkFixed: up now attaches the load balancer first. Run up again with the same flags to complete the cluster.
no primary found, wait and try againThe nodes are not ready, or there is no leader. Check patronictl list.
ssh ...: exit status 255SSH cannot connect. Check your key, --ssh-identity, the --ssh-allow ranges, or the tailnet.
backups need PGHA_S3_ACCESS_KEY ...Export the two S3 variables for the first up.
Tailscale needs a TS_API_KEY API access tokenExport TS_API_KEY (tskey-api-…). TS_AUTHKEY still works when no API token is set.
Tailscale name <name> is already used (bootstrap log)An old tailnet device owns the name. Set TS_API_KEY so up can delete it, or delete it in the Tailscale admin console. Then run pgha up again.
Console: node agent failed: ...The node could not run the console script. Check that python3-psycopg2 is installed on the node.
Console: cannot execute ... in a read-only transactionThe SQL editor is read-only by default. Tick Allow writes, or run on the primary.
Console: this table has no primary keyRows are edited by primary key. Use the SQL editor, or add a primary key.
Target database is not emptydb import does not overwrite. Drop the database first if that is correct.
too many connections for roleThe project is at its limit. Raise --connections or add PgBouncer.
PgBouncer limits not updated on <node>The node was not reachable. Run pgha db sync.
A replica does not start after adoptAn extension package is missing. Install it on the node.
this cluster has an adopted server; down is blockedRead section 17.2 for the manual steps.
monitor needs PGHA_ALERT_WEBHOOKExport PGHA_ALERT_WEBHOOK as an https URL.
webhook must be httpsUse an https URL that has a host.
install failed on <name>That node did not get the files. The others did. Run pgha monitor install again.
