Highly available Postgres on Hetzner Cloud

One command creates three PostgreSQL nodes with automatic failover, a load balancer, backups and alerts. You see the monthly bill before anything is created.

$ curl -fsSL https://github.com/mantissatech/pgha-cli/releases/latest/download/install.sh | sh
Quick start All install options GitHub
terminal
$ export HCLOUD_TOKEN=your-read-write-token
$ pgha estimate          # monthly bill, creates nothing
$ pgha up                # shows the bill, asks, then creates
$ pgha status            # nodes, roles and addresses
$ pgha db create shop_api # a database and login for one project
$ pgha console           # the same, in your browser

Everything a production cluster needs

Standard, well-known parts. Nothing to run except the CLI.

Automatic failover

Each node runs PostgreSQL, Patroni and etcd. Patroni promotes a replica when the primary fails.

One address

A private load balancer sends port 5432 to the primary and port 5433 to the replicas.

See the bill first

estimate and up read live Hetzner prices and show the monthly bill before anything is created.

Project databases

One database and login per project, with connection limits and optional PgBouncer pools.

Encrypted backups

pgBackRest sends full, differential and WAL backups to S3 object storage, encrypted.

Web console

pgha console opens a local dashboard to create clusters, manage databases and watch tasks.

Alerts

A timer on each node checks Patroni, lag, disk and backups, and posts JSON to your webhook.

Private by default

No database port is open to the internet. SSH uses keys, or only your tailnet with Tailscale.

What it creates

The defaults below fit most projects. Flags change each one. up is safe to run again: it skips what exists.

Cloud resources
3 serverscx33, one each in fsn1, nbg1 and hel1
3 volumes1000 GB each, mounted at /mnt/pgdata
1 private network10.0.0.0/16, or an existing one with --network
1 firewallPublic inbound: SSH only
1 load balancerlb11, private address only
