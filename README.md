# pgha packages

This branch is the apt and yum repository for [pgha](https://github.com/mantissatech/pgha-cli). It is generated by `scripts/publish-linux-repos.sh`. Do not edit it by hand.

The apt repository is not signed yet. Set the `APT_SIGNING_KEY` secret and cut another release to publish a key.

## Ubuntu and Debian

```bash
echo "deb [trusted=yes] https://mantissatech.github.io/pgha-cli stable main" | sudo tee /etc/apt/sources.list.d/pgha.list
sudo apt update
sudo apt install pgha
```

## Fedora and RHEL

```bash
sudo tee /etc/yum.repos.d/pgha.repo >/dev/null <<'REPO'
[pgha]
name=pgha
baseurl=https://mantissatech.github.io/pgha-cli/yum
enabled=1
gpgcheck=0
REPO
sudo dnf install pgha
```

Binaries and checksums are also on the [GitHub releases](https://github.com/mantissatech/pgha-cli/releases).
